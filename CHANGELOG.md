# Changelog

Все заметные изменения проекта RedheadGuy Guide Bot.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.4.0] - 2026-08-20

### Добавлено
- Тёмная тема веб-интерфейса панели администратора.
- Интеграция WYSIWYG редактора Quill.js с расширенным форматированием.
- Карточки предпросмотра гайдов в стиле сообщений Telegram (`.telegram-card`).
- Публичный режим просмотра категорий и гайдов (без необходимости авторизации).
- Набор автотестов `pytest` для бота, веб-интерфейса и очистки HTML.

### Изменено / Исправлено
- Исправлена очистка HTML для Telegram (`clean_html_for_telegram` конвертирует теги `strong`, `em`, `ins`, `del`, `strike` в поддерживаемые `b`, `i`, `u`, `s`).
- Атомарное сохранение `data/guides.json` через временный файл (`.tmp`) и `os.replace` для исключения повреждения данных при перезапуске.
- Исправлены пути к изображениям с синтаксисом POSIX-слишей (`media/photos/...`).
- В `docker-compose.prod.yml` добавлен сервис `web` и корректное монтирование директории `./data`.

## [1.3.2] - 2026-08-20

### Добавлено
- Веб-редактор: загрузка картинки гайда прямо из панели (файл → `media/photos/`).
  Картинка автоматически показывается в боте над текстом гайда.
- Превью текущей картинки в форме редактирования и возможность её удалить.

### Исправлено
- Картинки показываются прямо в сообщении бота (раньше — только по ссылке).
- Web-контейнер монтирует общую папку `media/` (иначе загруженные картинки
  не попадали в том, который читает бот).

## [1.3.1] - 2026-08-20

### Исправлено
- Веб-редактор: вход через Telegram (принимаем и GET, и POST; ставим cookie на редирект).
- Бот: корректный вывод гайдов, созданных через TinyMCE (HTML чистится до Telegram-совместимого).
- Docker: bot монтирует всю папку `data/`, а не отдельный файл (иначе атомарная замена
  guides.json не видна боту).
## [1.3.0] - 2026-08-20

### Добавлено
- Веб-редактор контента на FastAPI (`web/`)
- Авторизация через Telegram Login Widget
- Rich text редактор TinyMCE (self-hosted)
- Drag-and-drop сортировка категорий и гайдов
- Живое превью гайда
- Счётчики на главной странице панели
- Отдельный контейнер `web` в docker-compose
## [1.2.0] - 2026-08-20

### Добавлено
- Поиск по гайдам (`🔍 Поиск` в главном меню): поиск по названию и тексту,
  регистронезависимый, с результатами в виде кнопок
## [1.1.0] - 2026-08-20

### Добавлено
- Экспорт контента в файл (`📦 Экспорт/импорт`) — резервные копии гайдов
- Импорт контента из файла JSON — восстановление и перенос между ботами
- Dashboard статистики в админке (`📊 Статистика`): пользователи, запуски,
  просмотры категорий и гайдов
- Уведомления администратору о новых пользователях бота
- Модуль учёта пользователей (`users.py`)

## [1.0.0] - 2026-08-20

### Добавлено
- Запуск бота на aiogram 3 (Python 3)
- Админ-панель: добавление, редактирование и удаление гайдов и категорий
- Хранение контента в JSON (`data/guides.json`)
- Аналитика действий пользователей (`logs/analytics.log`)
- Логирование: консоль + файл + аналитика
- Обработка ошибок и защита от двойных нажатий кнопок
- Поддержка картинок-инструкций
- Команды `/version` и `/about`
- Деплой через Docker Compose
