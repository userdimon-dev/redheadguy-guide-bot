# Changelog

Все заметные изменения проекта RedheadGuy Guide Bot.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-08-20

### Добавлено
- Экспорт контента в файл (`📦 Экспорт/импорт`) — резервные копии гайдов
- Импорт контента из файла JSON — восстановление и перенос между ботами
- Dashboard статистики в админке (`📊 Статистика`): пользователи, запуски,
  просмотры категорий и гайдов
- Уведомления администратору о новых пользователях бота
- Модуль учёта пользователей (`users.py`)

## [1.0.0] - 2026-08-20

### Добавлено
- Запуск бота на aiogram 3 (Python 3)
- Админ-панель: добавление, редактирование и удаление гайдов и категорий
- Хранение контента в JSON (`data/guides.json`)
- Аналитика действий пользователей (`logs/analytics.log`)
- Логирование: консоль + файл + аналитика
- Обработка ошибок и защита от двойных нажатий кнопок
- Поддержка картинок-инструкций
- Команды `/version` и `/about`
- Деплой через Docker Compose
