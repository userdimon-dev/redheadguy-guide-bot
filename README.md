# 🤖 RedheadGuy Guide Bot

Telegram-бот с гайдами по настройкам, подключению и сервисам RedheadGuy.
Работает на **aiogram 3** (Python).

## ✨ Возможности
- 📱 Пошаговые гайды по настройке приложений (Happ, Incy и др.)
- 🖥️ Инструкции для разных устройств (Windows, Android, iOS, Linux)
- 🔗 Кнопки с полезными ссылками
- 🖼️ Поддержка картинок-инструкций
- 📂 Контент в JSON (редактируется через админку)
- 🔐 **Telegram-админ-панель** — добавление/редактирование/удаление гайдов
- 📊 Аналитика действий пользователей (какие гайды смотрят)
- 📝 Логирование (консоль + файл)
## 🚀 Установка и запуск

### Вариант А: Docker Compose (рекомендуется для сервера)

Доступна только пользователям из `ADMIN_ID`. Позволяет:
- ➕ Добавлять категории и гайды (мастер-диалог)
- ✏️ Редактировать существующие гайды
- 🗑️ Удалять гайды и категории
- 📂 Смотреть текущий контент

├── logger.py            # настройка логирования
├── VERSION              # номер версии бота
├── Dockerfile           # сборка образа
