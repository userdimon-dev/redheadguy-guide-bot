# 🤖 RedheadGuy Guide Bot

Telegram-бот с гайдами по настройкам, подключению и сервисам RedheadGuy.
Работает на **aiogram 3** (Python).

## ✨ Возможности
- 📱 Пошаговые гайды по настройке приложений (Happ, Incy и др.)
- 🖥️ Инструкции для разных устройств (Windows, Android, iOS, Linux)
- 🔗 Кнопки с полезными ссылками
- 🖼️ Поддержка картинок-инструкций
- 📂 Лёгкое добавление новых гайдов

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone <ваш-репозиторий>.git
cd redheadguy-guide-bot
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте токен
- Создайте бота в [@BotFather](https://t.me/BotFather)
- Скопируйте токен в файл `.env`:
  ```
  BOT_TOKEN=ваш_токен_от_botfather
  ```

### 4. Запустите
```bash
python bot.py
```

## 📂 Как добавить новый гайд
Откройте файл `guides.py` и добавьте категорию или гайд по шаблону.
Бот автоматически подхватит изменения при следующем запуске.

## 🗂️ Структура проекта
```
redheadguy-guide-bot/
├── bot.py            # главный файл (логика бота)
├── config.py         # настройки / токен

├── keyboards.py      # клавиатуры
```
